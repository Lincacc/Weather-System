# 基于物理的天空、大气、云层渲染论文解读

> 原文：Sébastien Hillaire. *Physically Based Sky, Atmosphere and Cloud Rendering in Frostbite*. SIGGRAPH 2016 Course: Physically Based Shading in Theory and Practice.
>
> 这是一份工程文档，不是期刊论文。它把 Frostbite 的天空、大气、天体、体积云放进同一套 **PBR 参与介质** 里，并写明它们如何互相影响。下文只写原文给出的模型、系数和算法；Bruneton 预计算大气的逐步循环是该文明确依赖、但没有逐步展开的前置工作，用 **「落地补全」** 标出。不要把 2015 Horizon 的 Powder、2020 Hillaire 新大气模型倒灌进来。

---

## 1. 论文在解决什么问题

2014 年 Frostbite 切到 PBR 之后，灯光与材质解耦，同一份材质必须在任意光照下自洽。当时天空、雾、云仍是静态资产：全景天空贴图、天空色梯度、雾颜色、雾曲线，按时间段线性混合。HDR 下要保证每个时相、每次插值都颜色一致，美术成本极高；开放世界还要求昼夜和天气实时变，线性混合撑不住。

目标写得很具体：

- 可随太阳位置变化的真实天空与大气散射
- 随天气演化的体积云
- 光、材质、介质参数解耦，用物理量（σa、σs、σt、相位函数）而不是「雾颜色」
- 天空、云、不透明、透明、粒子、GI 必须互相影响，不能各画各的
- 同时服务 30 FPS 与 60 FPS 的产品（Xbox One 上可摊销）

先行工作：Nishita / Bruneton / Elek / Yusov 的大气；Schneider 2015 的体积云。Frostbite 的增量不是再发明一朵云，而是 **把云做成能量守恒的参与介质，并与预计算大气、太阳圆盘、高度雾、阴影、GI 接成一张网**。

## 2. 总体架构

```
大气系数 (Rayleigh / Mie / Ozone)
        │  预计算 LUT（可跨帧摊销）
        ▼
  透过率 LUT 2D  +  散射 LUT 3D
        │
        ├─► 太阳圆盘：外空间亮度 × 透过率（+ limb darkening）
        ├─► 天空背景
        ├─► 视锥 froxel 大气透视（默认 32×32×16）
        └─► 高度雾：用视平线 LUT 亮度着色
                │
天气图 + 云型剖面 + 3D 噪声 ──► 体积云 ray march
                │                 （解析积分 + 双瓣 HG + Wrenninge 多散射）
                ├─► 云阴影 2D 投射到世界 / 粒子 / GI
                ├─► 云的加权平均深度 ← 采样一次大气透视
                └─► 半球平均云透过率与亮度 → 修正大气透视
```

模块边界：大气 LUT 不管云的形状；云只贡献密度场和一次散射/多散射近似；两者的耦合全部走「透过率 × 入射亮度」而不是贴颜色。

## 3. 实现原理

### 3.1 参与介质：全文共用的物理

介质由球状粒子组成，各向同性（散射概率与入射方向无关），但允许不对称相位（散射能量随方向变）。忽略发热发光。符号：

| 符号 | 含义 | 单位 |
| --- | --- | --- |
| σa | 吸收 | m⁻¹ |
| σs | 散射 | m⁻¹ |
| σt = σa + σs | 消光 | m⁻¹ |
| ρ = σs / σt | 反照率 | 无量纲 |
| p | 相位函数 | sr⁻¹ |
| L | 亮度 | cd·m⁻² |
| E | 照度 | lux（cd·sr⁻¹·m⁻²） |

单次散射路径亮度（点光源）：

\[
L_i(x_i,\omega_i)=Tr(x,x_s)\,L(x_s,\omega_i)+\int_0^S Tr(x,x_t)\,L_{\mathrm{scat}}(x_t,\omega_i)\,\sigma_s\,dt
\]

透过率由光学厚度决定：

\[
Tr(x_a,x_b)=\exp\left(-\int_{x_a}^{x_b}\sigma_t(x)\,dt\right)
\]

透过率要乘在三处：不透明表面（雾遮挡）、介质自身的 in-scatter（自遮挡）、散射点到光源（体积阴影）。体积可见性：

\[
Vis(x,L)=\mathrm{shadowMap}(x,L)\cdot Tr(x,x_L)
\]

反照率 ρ→0 是黑烟，ρ→1 是空气 / 云。云的测量值 ρ≈1，因此可取 σs = σt。

相位按粒子尺度相对波长 \(x=2\pi r/\lambda\) 分类：

- \(x \ll 1\)：Rayleigh（空气分子）
- \(x \approx 1\)：Mie（尘、雾、云滴，实时用 HG 近似）
- \(x \gg 1\)：几何散射（虹、雾虹，游戏里通常不跑完整 Mie）

公式：

\[
p_{\mathrm{iso}}=\frac{1}{4\pi},\quad
p_{\mathrm{Ray}}=\frac{3}{16\pi}(1+\cos^2\theta),\quad
p_{\mathrm{HG}}(\theta,g)=\frac{1-g^2}{4\pi(1+g^2-2g\cos\theta)^{1.5}}
\]

Schlick 近似可去掉幂运算，\(k\approx 1.55g-0.55g^3\)，但 \|g\| 很大时误差明显、银边变弱，云不要用它顶 HG。

波长只保留 RGB：680 / 550 / 440 nm。光谱渲染实时扛不住。

直观：σs 偏蓝时，浅处偏蓝、深处红光更能走远（与夕阳同一机制，只是尺度不同）。密度升高后行为变复杂，极厚时可接近皮肤那种「红光走得更远」。g→1 时介质在光源方向变亮，厚介质边缘留下银边。

### 3.2 天空与大气

蓝天是太阳光在大气里的 Rayleigh 散射；夕阳变红是因为路径变长、蓝光先被散射掉。近地大粒子做与波长几乎无关的 Mie 前向散射，造成太阳周围的晕。

**默认地球系数（原文 Table 2）：**

| 组分 | 散射 σs (m⁻¹) | 消光 | 高度分布 |
| --- | --- | --- | --- |
| Rayleigh（分子） | (5.8e−6, 1.35e−5, 3.31e−5) | = σs | exp(−h / 8.0 km) |
| Mie（尘） | ≥ 2e−6（随天气/污染） | 1.11 σs | exp(−h / 1.2 km) |
| Ozone | 0 | σa_O3 | 与 Rayleigh 相同 |

他们沿用 Riley / Bruneton 的 Rayleigh 数，即使自己用折射率公式算出的不完全一样。Mie 强度交给美术，用来做污染或沙尘。

臭氧对晨昏天顶的蓝很关键。按海平面空气浓度与 Serdyuchenko 截面恢复：

\[
\sigma^{O_3}_a=(3.426,\ 8.298,\ 0.356)\times 0.06\times 10^{-5}
\]

物理上臭氧应集中在约 32 km，RGB 近似下那样放会出怪结果，所以改成与 Rayleigh 同一指数层，直接加进 Rayleigh 消光。不加臭氧，晨昏天空会偏黄。他们试过光谱→XYZ 再裁到 sRGB，会得到负吸收，这条路放弃了。

**LUT 策略（Bruneton + Elek + Yusov）：**

- 用 Elek 的 **3D 散射 LUT**，丢掉视线–太阳的方位角，因此 LUT 里 **没有地球影子**。对地面游戏够用。
- 地平线精度用 Yusov 参数化，避免 Bruneton 在仰角 0、相机贴地时的条带。映射参考代码在原文附录 A。
- 透过率 LUT 仍是 2D：高度 × 视线天顶角（球对称）。
- 每帧把当前相机的散射亮度烘焙进视锥 **froxel**（默认 32×32×16），不透明、透明都能廉价采样；透明在 Frostbite 里按顶点采。这比每像素多次采 3D LUT 便宜，也保证透明与不透明的雾一致。
- 高度雾仍可加（Wenzel）。颜色取 3D LUT 在视平线的亮度（因为丢掉了方位角，一条视平线一个值就够），再乘每像素相位。近处高度雾、远处大气、天空才能接上。
- 太阳方向变了只采样 LUT；改大气高度或系数必须重建 LUT。完整重建约 3.5 ms（含多散射），摊到 19 帧约 0.22 ms/帧，并在「上一份有效」与「正在算的」之间 lerp。60 FPS 标题靠这个才能用。

Xbox One 天空：720p 主视图 0.42 ms，froxel 0.05 ms。Need for Speed 2016、Mirror’s Edge Catalyst 已上船。换系数就能画外星：火星日间偏黄、日落偏蓝，他们用目测系数做过延时日落。

### 3.3 太阳、月亮、星

太阳视直径约 0.527°–0.545°。美术给出的是 **天顶、已经过大气透过率之后** 的地面照度 \(E_s^{\mathrm{zenith}}\)（地球约 1e5–1.2e5 lux），不要让美术去猜外空间亮度。

换算链：

1. 把太阳当圆盘，立体角 \(\omega_s=2\pi(1-\cos(\theta/2))\)，约 6.64e−5–7.11e−5 sr。
2. \(L_s^{\mathrm{zenith}}\approx E_s^{\mathrm{zenith}}/\omega_s\)。0.545°、120000 lux 时约 \(1.69\times 10^9\) cd·m⁻²。
3. 沿天顶积分透过率 \(Tr^{\mathrm{zenith}}\)，外空间亮度 \(L_s^{\mathrm{outer}}=L_s^{\mathrm{zenith}}/Tr^{\mathrm{zenith}}\)。假设各波长透过率不为 0。
4. 画角直径匹配的圆盘，每像素乘当前方向的大气透过率：\(L_s=Tr^{\mathrm{sun}}\,L_s^{\mathrm{outer}}\)。

圆盘变大则亮度自动变暗，场景总光通量与外观一致。黄昏低曝光时若不乘透过率，太阳会把画面bloom爆。默认大气下天顶透过率约 (0.925, 0.861, 0.755)，地平线约 (0.0499, 0.004, 4.1e−5)。

Limb darkening：太阳是球，边缘视线更斜、光在气体里走得更远，盘心比边缘亮。附录 B 给了 Neckel 和 Hestroffer–Magna 两套波长相关模型，实时也可烘焙成一张径向梯度。

月亮：视直径 0.488°–0.568°，地面照度约 0.26 lux，亮度约 3658 cd·m⁻²。可用反照率贴图乘这个亮度。月相照明当时 Frostbite 没做，交给美术摆。星：地面贡献约 3e−2 W/m²，可用 Planck 定律按温度上色。环境反射立方体要能抓住日/月/星，卷积后间接光才一致。

### 3.4 云

造型路线跟 Schneider 2015 相同：程序噪声 + 天气图 + ray march + 时间积分。差别在材质必须进 PBR：能量守恒、光与材质分离、能跟大气互相改。

**介质：** Hess 等测得水云单次散射反照率 ρ=1，消光 σt 在层云约 [0.04, 0.06] m⁻¹、积云约 [0.05, 0.12] m⁻¹（550 nm）。因此 σs=σt。只有单次散射时，厚云只会在表面亮、内部像脏烟；发白、能看穿暗面结构，靠多散射。

**美术输入：**

- 天气图（世界 XZ，可平铺、可静态可动态）
  - R：二维投影密度
  - G：云型索引
- 云型剖面图（U=云型，V=层内归一化高度）
  - R：该高度的密度轮廓（可画多层或砧状积雨云）
  - G：侵蚀量，0 光滑、1 被高频 3D 噪声按 Schneider 方式挖空
- 两张可平铺 3D 噪声
  - noiseL：Perlin-Worley + 多层 Perlin，打散天气图重复、给基础形状
  - noiseH：多层 Worley，侵蚀边缘、出花椰菜（正文如此；Figure 32 图注写成多层 Perlin，以正文为准）

Frostbite 把噪声收成 **单通道体积纹理**，shader 里不再做 RGBA 加权。带宽下降，外观相当。生成代码见 [TileableVolumeNoise](https://github.com/sebh/TileableVolumeNoise)。纹理尽量小，减 cache miss。

云是单一参与介质：σa、σs、双瓣相位；空间上只变密度。

**光照分量（原文 Figure 33）：** 背景透过率 → 环境散射 → 无阴影太阳散射 → 自阴影太阳散射 → 加上前向相位。图示用 21 样本。

环境：采全局 SH probe。预算不够做 AO，也不好为程序噪声预积分遮挡，所以只用 probe 的直流项。结果往往偏亮，给美术 [0,1] 缩放；接大气散射会偏蓝，再给去饱和。再用云层高度线性梯度，默认假设环境只来自天空、忽略地面反弹。可把梯度改成 [a,1] 表示地面贡献 a，或分别采 probe 上/下半球。这些控制原文承认 **不是物理的**，只为打到美术目标。

太阳体积阴影：每个视线样本朝太阳直线步进 **4 次**，步长按常数倍递增（越走越稀），样本位置带时间抖动，合起来是软阴影。不是 HZD 的 6 次 cone。

时间积分：单 pass。每帧把样本在步长区间内随机偏移，当前帧与历史做指数滑动平均；相机一动就按新旧投影重投影，避免快转糊掉。这样能大幅减每帧步数（Figure 34：14 步有无时间积分对比）。

**步进积分是这篇相对 HZD 最硬的修正。** 普通循环要么先加散射再乘透过率（整步不衰减，不守恒），要么先乘透过率再加散射（整步都按末端衰减，过暗）。对薄雾误差小，σs 一大就炸。梯形法则更接近，但仍系统性偏亮。解析解：在步长 d 内把 σt 和源项 S 当常数，

\[
\int_0^d e^{-\sigma_t x}S\,dx=\frac{S-S\,e^{-\sigma_t d}}{\sigma_t}
\]

σt=0 时除零，clamp 到小 epsilon。21 步就能收敛到 512 步朴素积分的亮度；形状精度仍随步数提高，但 **亮度不再绑死在步数上**。这对 HDR 高低对比场景是刚需。原文 Listing 2 把 `sunLuminance` 直接当 S、没有乘 σs，与附录 C 以及 Listing 1 不一致。实现必须用 **S = σs · L**（L 已含阴影与相位）。ρ=1 时退化为 \(L(1-T)\)。

**双瓣相位：** 真实云相位有极尖的前向峰、约 120° 雾虹、宝光。游戏评不起。单瓣强前向 HG 在背光时只剩环境，暗面发闷。

\[
p_{\mathrm{dual}}(\theta,g_0,g_1,w)=\mathrm{lerp}(p_{\mathrm{HG}}(\theta,g_0),\,p_{\mathrm{HG}}(\theta,g_1),\,w)
\]

一瓣前向保银边，一瓣后向保背光结构。

**多散射（Wrenninge 2013）：** 路径追踪、预计算 collector、体积迭代都超预算。改成 N 个散射倍频相加，第 n 个倍频替换：

\[
\sigma_s'=\sigma_s a^n,\quad \sigma_e'=\sigma_e b^n,\quad p'(\theta)=p(\theta\cdot c^n)
\]

必须 **a ≤ b**，否则 σs 会超过 σt，凭空造能量。优点是步进时一次算完所有倍频；缺点是没有侧向/后向多散射、没有锥扩散。实践上能让厚云仍然透光、暗面有内部结构，云不再像烟。产品性能数字用的是 N=2。

**与大气的双向耦合：**

云通常又高又远，不乘大气透视会在地平线跟地面接不上。步进里每步采 froxel 太贵。改两步：

1. 用透过率加权的平均前表面深度（透过率=1 的空样本跳过）

\[
\mathrm{Depth}_{cloud}=\frac{\sum_n Tr(x_n)\,\mathrm{Depth}(x_n)}{\sum_n Tr(x_n)}
\]

2. 用这个深度 **采一次** 大气透视，打到已积分的云亮度/透过率上。

反过来，厚云层会挡住天空光、高反照率云会往大气里填光：

\[
L_{AP}\leftarrow L_{AP}\cdot Tr_{cloud}+L_{cloud}
\]

做法：云对黑背景画一遍，得到每像素散射亮度与透过率，再对地面半球求平均，去乘/加 froxel 里的太阳散射。不做这一步，乌云底下的大气仍然亮得像晴空。

**阴影与 GI：** 云透过率烘焙成一张 2D 贴图，按相机附近 **平地球** 投到世界，打不透明、透明、粒子；Enlighten 更新时也采这张图。平地球对典型行星尺度够用。

**性能（Xbox One，最坏：看向地平线、云占 3/5 屏、16 样本/pass、半分辨率主视图、平面反射 1/4、N=2）：** 720p 主 0.91 ms / 反射 0.14 ms；1080p 主 1.60 ms / 反射 0.20 ms。Need for Speed Payback 是第一款上船的 EA 游戏。

云画在所有几何后面。要与高山相交，必须步进到最近深度，且低分辨率合成需要降采样深度 + 双边上采样。当时没做。

## 4. 实现步骤（伪代码）

### 4.1 大气介质与 LUT 预计算

```
function SigmaRayleigh(h):
    return sigmaRay_s * exp(-h / 8000)          // (5.8e-6, 1.35e-5, 3.31e-5)

function SigmaMie(h):
    s = sigmaMie_s * exp(-h / 1200)             // >= 2e-6
    return (s, 1.11 * s)                        // (σs, σt)

function SigmaOzone(h):
    return (3.426, 8.298, 0.356) * 0.06e-5 * exp(-h / 8000)

function Extinction(h):
    ray = SigmaRayleigh(h)
    mieS, mieT = SigmaMie(h)
    return ray + mieT + SigmaOzone(h)

function ScatteringCoeffs(h):
    return (SigmaRayleigh(h), SigmaMie(h).σs)
```

透过率 LUT（落地补全：沿视线 march 到大气顶）：

```
function ComputeTransmittanceLUT(u, v):
    (h, cosView) = TransmittanceUvToParams(u, v)   // 附录 A 逆映射
    ro = (0, earthR + h, 0)
    rd = DirFromCos(cosView)
    tEnd = RaySphereFar(ro, rd, atmosphereR)
    τ = 0
    for i in 0..N-1:
        p = ro + rd * t(i)
        τ += Extinction(length(p) - earthR) * dt
    return exp(-τ)
```

散射 LUT 用 Elek 的 3D：高度 × 视线天顶 × 太阳天顶。单次散射沿视线积分，每步朝太阳再积透过率，乘 Rayleigh / Mie 相位；多阶把上一次 in-scatter 当场光再积分，累加进 LUT（Bruneton 循环，落地补全）。方位角丢掉，所以没有地球本影。地平线两侧用 Yusov 的 cosHorizon 切开，幂 0.2 把分辨率堆到地平线。

```
function UpdateLutAmortized(frame):
    // 原文：整表 3.5 ms，摊 19 帧 → 0.22 ms，两份有效结果 lerp
    slice = frame % 19
    BakeLutSlice(slice, lutWrite)
    if slice == 18:
        swap(lutRead, lutWrite)
    skyLut = lerp(lutPrevValid, lutRead, slice / 19)
```

### 4.2 视锥大气透视与高度雾

```
function BakeAerialPerspective(camera):
    for each froxel (x, y, z) in 32×32×16:
        p = FrustumPoint(camera, x, y, z)
        viewDir = normalize(p - camera.pos)
        (L, Tr) = SampleScatteringLUT(p, viewDir, sunDir)
        apVolume[x,y,z] = float4(L, luminance(Tr))   // 或分通道透过率

function ApplyHeightFog(p, viewDir):
    Lh = SampleScatteringLUT_horizon(camera.height, sunDir)  // 3D LUT 使单次采样合法
    phase = RayleighPhase(viewDir, sunDir) + MiePhase(...)
    fog = HeightFogFactor(p.y)                               // Wenzel
    return fog * Lh * phase
```

不透明用深度取 froxel；透明按顶点取。高度雾与 froxel、天空必须同一套 LUT 着色。

### 4.3 太阳圆盘

function SunSolidAngle(angularDiameterRad):
    return 2π * (1 - cos(0.5 * angularDiameterRad))

function PrepareSun(E_zenith, theta, sky):

### 4.4 云密度

```
function SampleCloudDensity(p, weatherTex, typeTex, noiseL, noiseH):
    uv = p.xz / weatherWorldSize
    w = weatherTex.sample(uv)                  // R 密度, G 类型
    h = saturate((p.y - cloudMin) / (cloudMax - cloudMin))   // 等高层
    profile = typeTex.sample(float2(w.g, h))   // R 高度密度, G 侵蚀

    base = noiseL.sample(p * shapeScale + wind * time)   // 单通道
    density = w.r * profile.r * base
    if density <= 0: return 0

    erosionAmt = profile.g
    detail = noiseH.sample(p * detailScale + wind * time)
    density = saturate(density - erosionAmt * detail * edgeFactor(density))
    return density
```

`edgeFactor` 让侵蚀发生在边缘（Schneider 的 remap 侵蚀）。原文没有写出完整 remap 式，密度合成以天气 × 剖面 × 低频，再按剖面 G 挖高频。

### 4.5 相位、多散射、解析积分

```
function HG(cosTheta, g):
    g2 = g * g
    return (1 - g2) / (4π * pow(1 + g2 - 2*g*cosTheta, 1.5))

function DualLobe(cosTheta, g0, g1, w):
    return lerp(HG(cosTheta, g0), HG(cosTheta, g1), w)

function SunShadowOpticalDepth(p, sunDir):
    // 原文：4 次，步长按常数倍递增 + 抖动
    τ = 0
    ds = shadowBaseStep * jitter
    q = p
    for i in 0..3:
        q += sunDir * ds
        ρ = SampleCloudDensity(q, ...)
        τ += ρ * σt * ds
        ds *= shadowStepMul
    return τ

function SourceTerm(p, viewDir, sunDir, ρ, octave):
    // Wrenninge 倍频：σs' = σs a^n, σt' = σt b^n, 相位变「更钝」
    σs_n = σs * pow(a, octave)
    σt_n = σt * pow(b, octave)          // 必须 a <= b
    g0_n = g0 * pow(c, octave)          // 原文写 p(θ·c^n)，实现上缩 g 更常见
    phase = DualLobe(dot(-viewDir, sunDir), g0_n, g1 * pow(c, octave), w)
    TrLight = exp(-SunShadowOpticalDepth(p, sunDir) * pow(b, octave))
    Lsun = sunIrradiance * TrLight * phase
    Lamb = Ambient(p)                   // SH 直流 × 美术缩放 × 去饱和 × 高度梯度
    return ρ * (σs_n * (Lsun + Lamb)), σt_n
```

注意：原文 Listing 2 漏乘 σs。正确的步内积分：

```
function IntegrateSlab(S, σt, ds, T):
    σt = max(σt, 1e-7)
    stepT = exp(-σt * ds)
    integ = (S - S * stepT) / σt        // S 已含 σs·L
    return (T * integ, T * stepT)
```

### 4.6 云视线步进 + 时间复用

```
function MarchClouds(uv, camera, sun):
    rd = WorldRay(uv)
    (t0, t1) = IntersectCloudSlab(camera.pos, rd, cloudMin, cloudMax)
    ds = (t1 - t0) / sampleCount         // 产品最坏 16；图示 21
    jitter = rand(uv, frame)             // 在 [0, ds) 内偏置
    t = t0 + jitter

    L = 0
    T = 1
    depthNum = 0
    depthDen = 0

    for i in 0..sampleCount-1:
        if T < ε: break
        p = camera.pos + rd * t
        ρ = SampleCloudDensity(p, ...)
        if ρ > 0:
            S = 0
            σt_used = 0
            for n in 0..N-1:             // 产品 N=2
                Sn, σt_n = SourceTerm(p, rd, sun.dir, ρ, n)
                S += Sn
                if n == 0: σt_used = σt_n
            dL, T = IntegrateSlab(S, σt_used, ds, T)
            L += dL
            depthNum += T * t            // 原文用各样本 Tr 加权；T 是到相机的透过率
            depthDen += T
        t += ds

    meanDepth = (depthDen > 0) ? depthNum / depthDen : t1
    (Lap, Trap) = SampleAerialPerspective(uv, meanDepth)
    L = L * Trap + Lap * (1 - 最终云透过的互补，按合成约定)
    // 更干净：先得到云的 (L, T)，再 L' = Lap + Trap * L，alpha 用 1-T

    prevUV = Reproject(uv, meanDepth, prevViewProj)
    hist = history.sample(prevUV)
    out = lerp(hist, float4(L, T), emaAlpha)
    history[uv] = out
    return out
```

半分辨率渲染，平面反射四分之一。合成到全分辨率时，若以后要与山相交，需要降采样深度 + 双边上采样（原文未来工作）。

## 5. 细节注意

### 5.1 参与介质与单位

- **σ 的单位是 m⁻¹，密度是无量纲乘数。** 把天气图的 0–1 直接当 σt 会让云要么全透明要么实心墙。先用测量区间（层云 0.04–0.06，积云 0.05–0.12）标定「密度=1」对应的 σt。
- **透过率必须分通道。** 用 `mean(σs)` 做灰度体积阴影是原文 Figure 11b 的演示，物理上错；正确是 σt=σs+σa 按 RGB。
- **ρ 与能量守恒。** 云 ρ≈1 所以 σs=σt。多散射倍频若 a>b，σs 会大于 σt，HDR 下云会自己发光。
- **相位归一化。** HG 在球面上积分应为 1。双瓣 lerp 两个已归一化的 HG，权重 w∈[0,1] 即可，不要再乘额外增益去「打亮银边」。

### 5.2 大气 LUT

- **3D LUT 没有地球影子。** 日食带、轨道视角、需要本影的镜头会错。那是 Elek 的明确代价，不是 bug。要本影就得上 Bruneton 4D（原文未来工作）。
- **地平线必须用 Yusov 映射。** 线性存 cosθ，几乎所有分辨率都会浪费在天顶，贴地看地平线会出带。
- **改系数就要重建 LUT，动太阳不用。** 把重建摊到多帧，并 lerp 新旧表，否则 3.5 ms 进不了 60 FPS。
- **臭氧加在 Rayleigh 消光上，不要单独做 32 km 层。** RGB 下按真实高度会出原文说过的意外颜色。
- **froxel 是一致性工具，不只是加速。** 透明按顶点采同一张 32×32×16，才能和地面雾对上。分辨率不够时近相机高度雾会有分层，用高度雾项补近场，不要盲目加大 froxel。
- **高度雾颜色取视平线 LUT，不是写死雾色。** 这是昼夜自动跟着走的前提；4D LUT 做不到「视平线一个值」，所以他们坚持 3D。

### 5.3 太阳

- **美术标的是天顶地面照度，不是外空间亮度。** 漏掉 `L_outer = L_zenith / Tr_zenith`，太阳和场景直射光会对不上。
- **必须每像素乘透过率。** 只画亮圆盘，黄昏太阳不会变红，还会 bloom 爆。
- **圆盘变大要降亮度。** 立体角变大、照度不变，则 L=E/ω 变小。不要把太阳当「emissive sprite」再单独调一张曝光。
- **透过率在地平线接近 0。** 除法要按通道 clamp；蓝通道 4e−5，不保护会 inf。
- Limb darkening 是盘内梯度，不是大气效果。先乘 limb，再乘大气透过率。

### 5.4 云造型

- **天气图只有密度和类型，没有 HZD 的 precipitation 通道。** 雨云用类型剖面画成砧状/厚积雨，再用密度拉高，不要误加第三通道当原文。
- **类型剖面的 V 是层内高度。** 这是美术画多层云和砧状云的手段，替代 HZD 的三个解析预设。
- **噪声用单通道。** 再存 RGBA 再 shader 里 fBm，是在付 HZD 的带宽，原文特意改掉了。
- **正文：noiseH = Worley octaves。** 与 Figure 32 图注冲突时跟正文。
- **侵蚀量来自类型图 G，不是全局常数。** 积云边缘要挖、层云要滑，必须随类型变。

### 5.5 云光照与积分

- **不要用「先 S 后 T」或「先 T 后 S」。** 厚云会能量爆炸或发黑。用解析式，S=σs L。
- **对照 Listing 2 时补上 σs。** 原文代码块与附录推导不一致，以附录和 Listing 1 的源项为准。
- **单瓣 HG 不够。** 背光发闷不是环境光太暗，是缺后向瓣。
- **多散射倍频在步进内一次累加。** 不要每倍频单独再 march 一遍。N=2 是产品默认；N=3 原文标成「夸张」。
- **太阳阴影是 4 次几何递增，不是 6 次 cone。** 软边来自递增步长 + 时间抖动。把 HZD cone 塞进来就不是这篇的模型。
- **环境是 SH 直流 + 美术缩放 + 去饱和 + 高度梯度。** 原文明确这不是物理项。不要指望它自动对上地面反弹；要地面色就采下半球或把梯度下端抬到 a。
- **时间积分是 EMA + 重投影，不是 4×4 的 1/16 更新。** 每帧全更（低分辨率）但步数少、靠抖动攒样本。失败时会鬼影，必须按深度重投影。

### 5.6 耦合与合成

- **云不采 froxel 逐步，只在加权平均深度上采一次。** 每步加采样会把 0.91 ms 打爆。空样本（T=1）必须从深度平均里剔除，否则平均深度被「空气」拉远。
- **大气必须被云改。** 只把大气打到云上、不把云打回大气，乌云下仍是晴空散射（Figure 41 中图）。
- **云阴影是 2D 平投影。** 大行星曲率、深谷会错。原文认为相机附近够用。
- **云目前画在所有东西后面。** 与山相交是未来工作；半分辨率合成必须双边，否则山脊会糊。
- **反射/环境立方体也要跑天空和云。** 原文性能表单列平面反射，就是为了全系统同一套光。

### 5.7 不要从邻篇倒灌

这篇 **没有** Powder 糖粉项、没有 cheap/full isosurface 切换、没有 1/16 像素更新、没有 6 次 cone。它用解析积分 + Wrenninge 倍频 + 双瓣 HG 解决厚云发黑和能量漂。实现「这篇」时不要先搬 HZD 的 Beer–Powder 当多散射。

## 6. 总结结论

这篇文档的核心不是新的噪声，而是 **把天空、大气、天体、云收成同一套参与介质，并在主机预算里保住能量守恒和系统间耦合**。

结论五条：

1. **参数必须是介质参数。** 美术调 σs/σa/相位/照度，而不是「雾颜色」「云颜色」。这样昼夜、外星、天气才能共用同一份材质。
2. **大气靠 LUT + 摊销，不靠每像素 march。** 3D 散射表丢掉方位角，换来高度雾单次采样和可负担的重建；froxel 让透明/不透明共用一次散射。
3. **太阳是有立体角的光源。** 由天顶照度反推外空间亮度，再乘透过率和 limb darkening。圆盘、直射光、Bloom 才能一起对。
4. **云的正确性来自积分和散射模型，不是步数。** 解析步内积分让 16–21 步亮度收敛；双瓣 HG 救背光；Wrenninge 倍频（a≤b）让厚云发白且暗面有结构。造型仍走 Schneider 的天气图 + 噪声。
5. **耦合是产品观感的一半。** 大气透视打到云、云覆盖打回大气、云阴影进 GI 和粒子——缺任何一条，昼夜天气一变就会露出「几套各画各的」。

工程次序：先把大气 LUT 和太阳圆盘在无云场景对上（天顶蓝、地平线红、太阳不爆）；再上云的解析积分与双瓣，用全分辨率验证能量不随步数漂；最后接 froxel 双向耦合、2D 云阴影和时间 EMA。次序反了，LUT 条带、积分漏光、乌云下晴空会缠在一起。
