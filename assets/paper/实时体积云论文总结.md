# 实时体积云论文总结

> 原文：Andrew Schneider, Nathan Vos. *The Real-time Volumetric Cloudscapes of Horizon: Zero Dawn*. SIGGRAPH 2015 Advances in Real-Time Rendering Course.
>
> 本文档解读的是该课程幻灯片，不是期刊论文。幻灯片给的是系统拆解与视觉证据，完整可编译公式由同一作者稍后写进 GPU Pro 7 章节 *Real-Time Volumetric Cloudscapes*。下文把两者分开标注：**「讲座原文」** 只写幻灯片明确给出的内容；**「落地补全」** 写 GPU Pro 7 / 社区按该系统重建的可执行细节，避免把 2016 年 Frostbite、2022 年 Nubis Evolved 的后续改动误当成 2015 原文。

---

## 1. 论文在解决什么问题

Guerrilla 过去在 *Killzone* 里用 Photoshop 手摆 billboard 和 skydome，时间固定，光照可预烘焙。*Horizon: Zero Dawn* 换成开放世界后，这套资产方案同时撞上四件事：

- 玩家可以走到目中所见的任何地方，包括山顶，天空约占半屏。
- 有完整昼夜循环，不能为某一时刻预烘焙一套图。
- 天气会演化，云必须跟着 coverage / 降水 / 云型变。
- 需要多种云型（层云、积云、层积云、积雨云，以及高层卷云），并且看起来像「正在发生」而不是噪声贴图。

他们试过流体求解器长云、多边形化体素云、球面谐波烘焙、多朝向 billboard、整套体素云烤成 skydome。共同失败点是：云不会随时间演化、无法从玩家头顶掠过、内存与 overdraw 高、云与云之间的互遮挡很难做。最终放弃「云是资产」，改成「云是由规则驱动的体积场」。

约束写得很硬：PlayStation 4 上大约 **2 ms**，大约 **20 MB** 显存，PSSL + C++，整片天空只依赖少量程序噪声纹理，不再堆 skydome / billboard。

艺术目标也写死了：可美术导向、能表示多种云型、接入天气、会演化、看起来够「史诗」。

## 2. 总体架构

系统按四段拆开，这也是实现时应遵守的模块边界：

```
天气场 (coverage, precipitation, type)
        │
        ▼
  密度采样器 (低层形状 + 高层细节侵蚀)
        │
        ▼
  视线 ray march（便宜步进 / 完整步进切换）
        │
        ▼
  朝阳 cone 光照（Beer × HG × Powder × 降水吸收）
        │
        ▼
  高层 2D 卷云 + 大气着色 + 时间重投影
```

关键抽象只有一个：**采样器**。视线步进与朝阳光照步进调用的是同一套密度函数，只是「完整版」和「便宜版」的指令量不同。形状、天气、动画全部发生在采样器里，渲染器只负责在球壳大气里决定何时采样、采几次。

## 3. 实现原理

### 3.1 气象学只取可建模的经验规则

讲座引用 1961 年气象书 *The Clouds*，留下的不是物理仿真，而是一组可写进 shader 的抽象：

- 温度随高度下降，密度随温度下降而上升 → 云底稀、云体中上部更实。
- 高密度区域降水 → precipitation 通道专门加厚并加吸收。
- 风向随高度变化、热气流上升、密区上升时呈圆形、稀区像雾一样扩散、大气湍流继续扭曲 → 分别对应高度梯度、Worley 团块、云底反相 Worley、curl 扰动。

云型分层也直接决定渲染预算：

| 类型 | 高度概念 | 2015 方案 |
| --- | --- | --- |
| Strato：层云 / 积云 / 层积云 | 约 1500–4000 m | 体积 ray march |
| Alto / Cirro | 4000 m 以上 | 多层滚动 2D 贴图，不进体积步进 |
| Cumulonimbus | 贯穿对流层 | 由 precipitation 把当前天气逼成高 coverage 积雨云 |

地球是圆的。在平地（例如海面）上，云会沿地平线「沉下去」。他们把低层云放进球壳大气，用射线与内外球求交得到步进区间；缩小大气半径还能人为压场景尺度，让远山与云的相对大小更好看。绘制半径约 **35000 m**；从约 **15000 m** 起把远景偏向 coverage ≈ 50% 的积云，保证地平线始终有变化、能压过山脊。

### 3.2 为什么不用普通 Perlin fBm

网上常见做法：在相机上方高度带里叠几层 Perlin，再乘一个高度渐变。结果是「好看的程序噪声」，缺两件真实照片里立刻能读出来的事：

1. 没有更大尺度的控制形状，看不出热气流正在把云「顶」上去。
2. 没有花椰菜状紧密团块（他们称为 billow）。云顶应圆、云底应丝。

Perlin 负责连通性，Worley 反相后负责紧密堆积的圆包。做法是：把多层反相 Worley 当成位移去膨胀 Perlin，得到 **Perlin-Worley**。这是整套造型的低频骨架。

### 3.3 噪声如何压进三张纹理

游戏里噪声必须是可平铺 3D 纹理，读次数和分辨率都要压到最低。讲座给出的打包是：

| 纹理 | 尺寸 | 通道 | 用途 |
| --- | --- | --- | --- |
| 低频形状 3D | 128³，4 通道 | R：Perlin-Worley；GBA：递增频率的 Worley | 云的主体 |
| 高频细节 3D | 32³，3 通道 | 递增频率的 Worley | 只在云边缘做侵蚀 |
| 2D curl | 128²，3 通道 | 无散度 curl 噪声 | 伪造流体湍流，扰动细节采样坐标 |

高频噪声永远是「从基础形状的边缘往里挖」，所以空区域根本不必读第二张 3D 纹理。这是后面「便宜步进 / 完整步进」的建模依据，不是单纯的 LOD 窍门。

### 3.4 天气场如何驱动云型

coverage 与 cloud type 是天气系统的函数，另有 precipitation 画雨云。天气图是一张铺在世界地图上的 2D 场，讲座给的通道约定：

- **R**：coverage，\[0, 1\]
- **G**：precipitation
- **B**：cloud type

模拟在玩法过程中推进，同时保留全局偏置，让美术能把天气「按在」某类气候上。默认是积云 + 层云：红多蓝少的区域变成层云。precipitation 会把地图从当前状态推向积雨云，讲座给出的经验阈值是 **coverage 约 70%** 时转入积雨云，并提高该处光吸收，让雨云更暗；同一信号驱动地面降雨特效。

过场可以不用模拟，直接用手绘天气纹理覆盖，E3 预告片就是这样做的。云整体沿给定风向平移。

三个低空云型不是三套模型，而是三个 **高度–密度预设**，在采样点按 type 混合。coverage 再决定该柱子里噪声被切掉多少。远景另有一条硬规则：15 km 以外强制偏向积云，避免地平线空、平、假。

### 3.5 密度如何从噪声变成「一块云」

讲座原文步骤：

1. 采低频 3D 纹理，乘高度信号，得到基础形状。
2. 再乘 coverage，并压低云底密度，使底部变丝、同时让云更自然地「出现」而不是整层糊上。物理对应：密度随高度增加。
3. 用 curl 扰动后的高频 Worley **减去** 基础形状的边缘（侵蚀）。云底把 Worley 反相，得到丝状底。

GPU Pro 7 把「乘 / 减」落实成 `Remap`，这是实现时真正该写的算子。`Remap` 把 `value` 从 `[oldMin, oldMax]` 线性映到 `[newMin, newMax]`，再 saturate。它的作用是 **用阈值雕刻**：低于阈值的噪声变成 0（空气），刚过阈值的部分被拉满成云体，边缘保持连续。不要用生硬的 `if (noise > coverage)`，那会产生切片感。

低频 Worley FBM 用来膨胀 Perlin-Worley，补上花椰菜团块，同时保住 Perlin 的连通性。coverage 雕刻之后再乘一次 coverage，让小碎云更淡、大云更实。

### 3.6 光照：三个外观目标，三项近似

他们只要三种看起来「像云」的光：

1. **体发光质感**（方向性散射 / 主透射）
2. **银边**（对着太阳看穿云）
3. **暗边**（背对太阳时，圆包边缘比缝隙更暗）

前两件有标准模型。第三件当时文献少，是他们自己的思想实验。

光子在云里做随机行走：出射、被吸收、或与其它光子 in-scatter。云物质被他们说成「光的收集器」：表面点几乎只拿到入射光；稍往里走，邻域 in-scatter 变多，缝隙比凸包更亮，直到深度大到 Beer 衰减重新占上风。这就是照片里花椰菜云的「糖粉」外观。电影里靠大量二次散射采样就能出；游戏必须用解析近似。

三项公式如下。

**Beer 定律**（主透射，讲座原文）：用光学厚度代替几何厚度，能量随深度指数下降。

\[
T_{\text{Beer}}(d)=\exp(-\sigma\,d)
\]

其中 \(d\) 是朝太阳方向积分到的光学深度（由 cone 采样的密度和给出），\(\sigma\) 是消光 / 吸收系数。降水区提高 \(\sigma\)。

**Henyey–Greenstein**（各向异性，讲座原文）：云更倾向前向散射，造成银边。每次取到光能量后乘相位函数：

\[
p_{\text{HG}}(\theta,g)=\frac{1-g^{2}}{4\pi\,(1+g^{2}-2g\cos\theta)^{3/2}}
\]

\(\theta\) 是视线与入射光方向的夹角，\(g\in(-1,1)\) 控制前向 / 后向。云常用小到中等的正 \(g\)。2015 讲座只用单瓣 HG；双瓣 HG 是后来常见改进，不是原文。

**Powder（糖粉，讲座原文 + 落地补全）**：把「深度越大、收集到的 in-scatter 越多」写成概率：

\[
T_{\text{Powder}}(d)=1-\exp(-2\,\sigma\,d)
\]

与 Beer 相乘得到他们戏称的 Beer–Powder：

\[
E_{\text{dir}}=T_{\text{Beer}}(d)\,T_{\text{Powder}}(d)\,p_{\text{HG}}(\theta,g)
\]

\(T_{\text{Powder}}\) 在 \(d=0\) 处为 0，表面被压暗；稍深后迅速升到 1，内部重新变亮。这不是物理闭合的多散射解，是外观拟合。

Powder 必须是视角相关的。讲座明确：这是背对太阳时才明显的效果，摄像机从对着太阳转到背对太阳时，暗边应变强。实现上用视线与太阳方向的点积去 lerp：对着太阳时 Powder 接近 1（不压边，把舞台留给 HG 银边）；背对太阳时才启用 Powder。

### 3.7 渲染：在球壳里决定「何时做贵的事」

视线从相机穿过球壳云层。不是沿途每一步都跑完整采样器。

- **便宜采样**：只读 128³ 低频 + 高度梯度 + coverage。步长更大。
- **完整采样**：再加上 32³ 细节、curl 扰动、云底反相。只在低频已经给出非零密度时做。

低频非零区域形成一个包住真云的 **isosurface**。击中这层壳之后，先 **后退一步** 再切到完整采样，避免大步长跨过云前缘、丢掉高频细节。alpha 累到 1 立刻停。若完整采样连续若干次密度为 0，切回便宜步进，直到再次撞上云或走出云层上界。

潜在步数：天顶约 **64**，地平线约 **128**。地平线射线更长，所以步数随视角拉高。数字是「潜在上限」，优化就是为了尽量提前退出。

光照不是沿太阳方向再做一次完整 ray march，而是 **朝太阳打一个 6 次采样的圆锥**：

- 5 次落在锥体内，平滑 6 次采样本来会有的条带，并用邻域密度给光照加权，得到廉价环境光感。
- 最后 1 次远远放在锥轴上，用来吃到远处云投下的影子。

cone 积分替代 Beer 公式里的深度 \(d\)。得到的能量再按视线方向的体积积分衰减，这是标准体积 ray march 的 in-scatter 累积。alpha 超过约 **0.3** 后，光照采样改走便宜密度，讲座称这一项让 shader 大约快一倍。

体积云步进结束后，再采高层 2D 卷云 / 高积云。它们是若干可平铺、不同速度与方向滚动的贴图，叠在体积云之上。高层云很薄，不值得放进体积循环。

着色是外观模型，不是光谱传输：

- 环境天空贡献随高度增加（云顶更「接」天空）。
- 直射由太阳色主导。
- 大气随深度遮挡云。

环境 + 直射之后，用深度通道把颜色衰减到大气色。昼夜循环因此是实时的：太阳色、太阳方向、大气色变了，云跟着变，无需预烘焙。整片天空的独特显存开销就是那两张 3D 噪声加一张 2D curl，而不是几十张 billboard / skydome。

### 3.8 时间重投影：从 20 ms 打到 2 ms

上述算法在当时大约 **20 ms**，不能进游戏。Nathan Vos 的方案：

1. 云画进低分辨率缓冲（讲座同时提到 quarter-res 与 half-res + 上采样）。
2. 每个 4×4 像素块每帧只新算 **1 / 16** 个像素。
3. 其余像素用上一帧重投影填。
4. 重投影失败处（屏幕边缘、遮挡突变）改用持续更新的低分缓冲。

这一项大约再快 **10 倍**。目标性能约 2 ms，成本主要来自完整采样时的指令数，而不是几何。没有时间复用，前面所有建模与光照技巧都进不了主机游戏。

## 4. 实现步骤（伪代码）

下面按一帧的数据流写。函数体是可直接翻译成 shader 的结构；数值来自讲座原文的用「讲座」标明，来自 GPU Pro 7 / 通行重建的用「补全」标明。

### 4.1 资源与天气

```
资源:
    texShape   : 3D, 128^3, RGBA   // R = Perlin-Worley, GBA = Worley FBM
    texDetail  : 3D,  32^3, RGB    // 递增频率 Worley
    texCurl    : 2D, 128^2, RGB    // curl
    texWeather : 2D, 世界 XZ       // R coverage, G precipitation, B type
    texCirrus[]: 2D 若干张         // 高层卷云 / 高积云

常量（讲座）:
    cloudMinH = 1500 m
    cloudMaxH = 4000 m
    drawRadius = 35000 m
    horizonBiasStart = 15000 m     // 之外偏向积云, coverage ~ 0.5
    earthRadius                       // 可缩小以压场景尺度
    stepsZenith = 64
    stepsHorizon = 128
    lightSamples = 6
    lightCheapAlpha = 0.3
    rainTypeCoverage = 0.7         // precipitation 推向积雨云
```

```
function SampleWeather(worldXZ, wind):
    uv = (worldXZ + wind.xz * time) / weatherScale
    w = texWeather.sample(uv)
    dist = length(worldXZ - camera.xz)

    if dist > horizonBiasStart:
        t = saturate((dist - horizonBiasStart) / (drawRadius - horizonBiasStart))
        w.r = lerp(w.r, 0.5, t)          // coverage → ~50%
        w.b = lerp(w.b, 1.0, t)          // type → cumulus

    if w.g 足够大:                        // precipitation
        w.r = lerp(w.r, 1.0, w.g)
        w.b = lerp(w.b, 1.0, w.g)        // 推向 cumulonimbus
        // 约 70% coverage 时视觉上变成雨云
    return w
```

### 4.2 高度梯度（三个数学预设）

讲座只说「三个低空云型的数学预设，在采样点混合」，没有给出多项式。通行写法是四元组 \((a,b,c,d)\) 表示「从 a→b 淡入、从 c→d 淡出」：

```
function Remap(v, oldMin, oldMax, newMin, newMax):
    return newMin + (v - oldMin) / (oldMax - oldMin) * (newMax - newMin)

function HeightFraction(p, minH, maxH):
    return saturate((p.y - minH) / (maxH - minH))   // 球壳里改用径向高度

function DensityHeightGradient(h, type):            // type ∈ [0,1]
    // 补全：stratus 薄层 / stratocumulus 中层 / cumulus 通高
    stratus        = (0.02, 0.05, 0.09, 0.11)
    stratocumulus  = (0.02, 0.20, 0.48, 0.625)
    cumulus        = (0.01, 0.0625, 0.78, 1.0)

    w0 = 1 - saturate(type * 2)
    w1 = 1 - abs(type - 0.5) * 2
    w2 = saturate(type - 0.5) * 2
    g = stratus * w0 + stratocumulus * w1 + cumulus * w2

    return smoothstep(g.x, g.y, h) - smoothstep(g.z, g.w, h)
```

### 4.3 密度采样器（系统核心）

```
function SampleDensity(p, weather, expensive):
    h = HeightFraction(p, cloudMinH, cloudMaxH)
    uvw = p * shapeScale + wind * time

    n = texShape.sample(uvw)                         // RGBA
    lowFBM = n.g * 0.625 + n.b * 0.25 + n.a * 0.125  // 补全：Worley fBm

    // 用 Worley 膨胀 Perlin-Worley，保留连通性并加入 billow
    base = Remap(n.r, -(1.0 - lowFBM), 1.0, 0.0, 1.0)
    base = saturate(base)

    base *= DensityHeightGradient(h, weather.b)

    coverage = weather.r
    // 补全：用 coverage 做阈值雕刻，再乘 coverage 让碎云更淡
    base = Remap(base, 1.0 - coverage, 1.0, 0.0, 1.0)
    base = saturate(base) * coverage

    // 讲座：压低云底密度，底部变丝
    base *= saturate(Remap(h, 0.0, 0.15, 0.1, 1.0))

    if base <= 0 or not expensive:
        return max(base, 0)

    // 讲座：curl 扰动高频采样坐标，云底扰动更强
    curl = texCurl.sample(p.xz * curlScale)
    p.xz += curl.xy * (1.0 - h) * curlStrength

    d = texDetail.sample(p * detailScale + wind * time)
    highFBM = d.r * 0.625 + d.g * 0.25 + d.b * 0.125

    // 讲座：云底反相 Worley → 丝状；云顶正向 Worley → 花椰菜
    wispy = 1.0 - highFBM
    billowy = highFBM
    erosion = lerp(wispy, billowy, saturate(h * 10.0))

    density = Remap(base, erosion * 0.2, 1.0, 0.0, 1.0)
    return max(density, 0)
```

便宜路径在 `base <= 0` 或 `expensive == false` 时返回，不读 `texDetail` / `texCurl`。

### 4.4 球壳求交与步数

```
function RaySphere(ro, rd, radius):
    // 返回射线与球体的远交点 t；无交则负
    b = dot(ro, rd)
    c = dot(ro, ro) - radius * radius
    disc = b * b - c
    if disc < 0: return -1
    return -b + sqrt(disc)

function CloudInterval(ro, rd):
    // ro 是相对地心的位置
    tInner = RaySphere(ro, rd, earthRadius + cloudMinH)
    tOuter = RaySphere(ro, rd, earthRadius + cloudMaxH)
    t0 = max(0, min(tInner, tOuter))
    t1 = max(tInner, tOuter)
    if t1 < 0: return invalid
    return (t0, t1)

function PotentialSteps(rd):
    // 讲座：天顶 64，地平线 128
    up = abs(rd.y)                       // 球壳里改用与地心径向的夹角
    return lerp(stepsHorizon, stepsZenith, saturate(up))
```

### 4.5 Beer / HG / Powder 与 cone 光照

```
function Beer(opticalDepth, sigma):
    return exp(-opticalDepth * sigma)

function Powder(opticalDepth, sigma):
    return 1.0 - exp(-opticalDepth * sigma * 2.0)

function HG(cosTheta, g):
    g2 = g * g
    return (1 - g2) / (4 * PI * pow(1 + g2 - 2 * g * cosTheta, 1.5))

function LightEnergy(opticalDepth, sigma, viewDir, sunDir, rain):
    sigmaEff = sigma * lerp(1.0, rainAbsorption, rain)   // 讲座：雨云提高吸收
    beers = Beer(opticalDepth, sigmaEff)
    powder = Powder(opticalDepth, sigmaEff)

    // 讲座：暗边在背对太阳时增强；对太阳时交给 HG 做银边
    awayFromSun = saturate(dot(viewDir, sunDir))         // view 与 to-sun 同向 ≈ 背对太阳
    powder = lerp(1.0, powder, awayFromSun)

    phase = HG(dot(-viewDir, sunDir), gAniso)
    return beers * powder * phase

function ConeOpticalDepth(p, sunDir, weather, viewAlpha):
    // 讲座：6 次，锥内 5 次 + 沿光方向一次远距离
    expensiveLight = (viewAlpha < 0.3)
    depth = 0
    t = 0
    for i in 0..4:
        offset = coneTangent * coneRadius(i) + sunDir * coneStep(i)
        s = p + offset
        t += coneStep(i)
        rho = SampleDensity(s, weather, expensiveLight)
        depth += rho * coneStep(i)
    // 最后一发拉远，吃远处投影
    sFar = p + sunDir * farDistance
    depth += SampleDensity(sFar, weather, false) * farDistance
    return depth
```

`coneTangent` 用任意与 `sunDir` 正交的基底；具体 6 个偏移向量讲座未给出，不要把某份 Shadertoy 的 kernel 当成原文数据。重要约束只有：锥角平滑条带、最后一发明显更远。

### 4.6 视线步进（含便宜 / 完整切换）

```
function MarchClouds(uv, camera, sun):
    rd = WorldRay(uv, camera)
    (t0, t1) = CloudInterval(camera.pos_geocentric, rd)
    if invalid: return (0, 0)

    maxSteps = PotentialSteps(rd)
    stepCheap = (t1 - t0) / maxSteps
    stepFull  = stepCheap * 0.5          // 完整采样用更小步长

    t = t0
    transmittance = 1.0                  // 视线透过率，对应 1 - alpha
    radiance = 0
    mode = CHEAP
    zeroStreak = 0
    ZERO_LIMIT = 3                       // 讲座：「连续若干次」零密度后切回便宜

    while t < t1 and transmittance > 1e-3:
        p = camera.pos + rd * t
        if length(p.xz - camera.xz) > drawRadius: break

        weather = SampleWeather(p.xz, wind)
        expensive = (mode == FULL)
        rho = SampleDensity(p, weather, expensive)
        ds = (mode == FULL) ? stepFull : stepCheap

        if mode == CHEAP:
            if rho > 0:
                t -= stepCheap           // 讲座：切完整采样前必须后退一步
                mode = FULL
                zeroStreak = 0
                continue
            t += stepCheap
            continue

        if rho <= 0:
            zeroStreak += 1
            if zeroStreak >= ZERO_LIMIT:
                mode = CHEAP
            t += stepFull
            continue

        zeroStreak = 0
        sigma = baseSigma
        viewAlpha = 1.0 - transmittance
        dLight = ConeOpticalDepth(p, sun.dir, weather, viewAlpha)
        energy = LightEnergy(dLight, sigma, rd, sun.dir, weather.g)

        ambient = skyColor * hFraction(p)                // 讲座：环境随高度增加
        inScatter = energy * sun.color + ambient

        // 标准体积积分：本步吸收 1-exp(-rho*sigma*ds)
        stepT = exp(-rho * sigma * ds)
        radiance += transmittance * (1 - stepT) * inScatter
        transmittance *= stepT

        t += stepFull

    // 讲座：体积步进结束后采高层 2D 云
    cirrus = SampleCirrusStack(rd, time)
    radiance = radiance + transmittance * cirrus.rgb
    transmittance *= (1 - cirrus.a)

    depth = t1                          // 或最后一次命中距离
    atmosphere = AtmosphereColor(rd, depth, sun)
    color = lerp(atmosphere, radiance, saturate(1 - fog(depth)))
    alpha = 1 - transmittance
    return (color, alpha)
```

更严谨的步内积分（把步进内透过率当解析积分，而不是把 \(T\) 当成整步常数）能减轻「步长一变亮度就变」。这是 2016 年后续优化文的补丁，不是 2015 原文，但实现时应该用：

```
optical = rho * sigma * ds
stepT = exp(-optical)
integratedT = (1 - stepT) / max(optical, 1e-6)
radiance += transmittance * integratedT * optical * inScatter
transmittance *= stepT
```

### 4.7 高层 2D 云与合成

```
function SampleCirrusStack(rd, time):
    // 讲座：若干种 cirrus / alto，不同速度、不同方向滚动
    acc = 0
    for layer in cirrusLayers:
        uv = SphericalUV(rd, layer.height) + layer.dir * time * layer.speed
        s = layer.tex.sample(uv) * layer.opacity
        acc.rgb = acc.rgb + (1 - acc.a) * s.rgb
        acc.a   = acc.a + (1 - acc.a) * s.a
    return acc
```

体积云应画在远景天空 / 大气之后、近景几何之前，或与大气做深度相关 lerp。讲座的合成顺序是：体积 in-scatter → 高层 2D 云 → 按深度衰减到大气色。

### 4.8 时间复用（能进游戏的那一项）

```
// 每帧只更新 4x4 里的 1 个像素；模式按 frameIndex 在 16 个相位间轮转
phase = frameIndex & 15
px = pixel.x & 3
py = pixel.y & 3
slot = py * 4 + px

if slot == phase:
    result = MarchClouds(uv, camera, sun)
    history[pixel] = result
else:
    prevUV = ReprojectToPrevFrame(uv, cloudDepth)
    if prevUV 在屏内且深度一致:
        result = history.sample(prevUV)
    else:
        result = lowResCloudBuffer.sample(uv)   // 讲座：边缘用低分缓冲顶上

upsample bilinear/bilateral 到全分辨率后与场景合成
```

低分缓冲本身可以每帧全更新，分辨率是最终图像的 1/4 或 1/2，专门给重投影失败当回退。讲座没有写 reprojection 的深度检验公式，实现时必须自己加：云没有不透明深度，通常用步进得到的首次命中距离或加权中心深度。

## 5. 细节注意

### 5.1 造型

- **不要用「噪声大于阈值」当云。** 必须 `Remap` 雕刻，再乘 coverage。硬阈值会切出层片，coverage 动画时会闪。
- **Perlin-Worley 在 R，Worley FBM 在 GBA。** 通道用反会只剩团块没有连通体，或只剩雾没有花椰菜。
- **高频只侵蚀边缘。** 把细节加到云核会把积云挖空。`Remap(base, erosion * k, 1, 0, 1)` 的 `k`（补全里常用 0.2）是边缘厚度，不是细节强度滑条。
- **云底反相 Worley 是造型，不是滤镜。** 不做这一步，底部会和顶部一样圆，读不出上升气流。
- **curl 加在细节采样坐标上，不要加在低频形状上。** 低频被 curl 搅动后，天气场对不出固定云体，积云会「融化」。
- **高度梯度是云型，不是装饰。** 层云必须是薄板，积云必须通高。三个预设在 type 上要用权重混合（中间是层积云），不要 `if type > 0.5`。
- **云底要单独减密度。** 只靠高度预设不够，讲座把「底部变丝」写成独立一步，对应密度随高度增加。
- **噪声必须可平铺。** 128³ / 32³ 会在大世界上重复。靠天气场的低频变化和远景积云偏置遮住平铺，不要把形状纹理做到 512³ 去「解决」平铺——预算不允许，讲座的显存故事就是压缩到这三张图。

### 5.2 天气与动画

- **天气图是世界 XZ 投影，不是屏幕空间。** 相机转时云必须钉在世界上。
- **coverage / type / precipitation 是同一套模拟的三个通道。** 降水不要另开一套积雨云模型，讲座是把现有场推向高 coverage + 高吸收。
- **15 km 远景偏置是产品规则。** 不做的话，模拟经常在地平线给出平层云，山脊背后会空。
- **过场用手绘天气纹理覆盖模拟。** 实时系统与镜头云不是两套渲染器，只换输入场。
- **风要作用在噪声 UV 和天气 UV 上，速度可以不同。** 形状走得比天气快，会有「云在天气场里生长 / 消散」的演化感；两者锁死会像贴花在滑。

### 5.3 光照

- **Beer 单独用会得到「实心棉花」。** 必须乘 HG，否则没有银边。
- **HG 单独用仍没有暗边。** 暗边是 Powder，不是把 \(g\) 调大。
- **Powder 一定要视角加权。** 对着太阳还乘 Powder，银边会被吃掉，和讲座的分镜相反。
- **雨云加的是吸收，不是把反照率涂灰。** 涂灰没有深度结构，加 \(\sigma\) 才有「更厚、更暗、仍是体积」。
- **cone 最后一发必须远。** 5 次近样本只解决局部平滑；远距离互遮挡全靠第 6 次。没有它，前景积云不会在后云上留下影子。
- **alpha > 0.3 后光照走便宜密度。** 这是讲座明确写出的 2× 加速。此时视线已经在云核里，高频侵蚀对阴影积分贡献小。
- **\(d\) 是光学深度，不是几何距离。** 用 `sum(density * step)` 代入 Beer，不要用到太阳的欧氏距离。
- **环境光随高度增加。** 云底偏暖 / 偏地面、云顶接天空，是昼夜能自动对上的关键。不要给整朵云一个常数环境色。

### 5.4 步进与积分

- **先求球壳交点，再步进。** 在「相机上方一个 AABB」里 march，地平线的云不会下沉，地球曲率整段失效。
- **切到完整采样前后退一步。** 大步长已经跨进云体的话，云前缘的丝状细节会被永远跳过，积云边缘变硬壳。
- **连续零密度才切回便宜模式。** 只看单次零值会在多孔云里频繁切换，既闪又打乱步长。
- **alpha = 1 立刻停。** 厚积雨云如果不早退，64–128 × 6 次采样会把 2 ms 打爆。
- **步数随地平线增加。** 固定 64 步时，远地平线采样间距过大，云会断成条。
- **亮度不要随步长漂。** 用 4.6 节的解析步内积分，否则 cheap/full 切换处会接缝。
- **视线透过率与 alpha 不要混用两套累加器。** 用 `T *= exp(-σρΔs)`，最终 `alpha = 1 - T`。再手写一份 `alpha += (1-alpha)*x` 很容易和光照衰减对不上。

### 5.5 时间复用与性能

- **没有 1/16 更新就不要指望 2 ms。** 讲座把 20 ms → 2 ms 主要记在这项上。建模与 cone 只能把「正确但贵」变成「正确」；能进游戏的是复用。
- **重投影必须处理失败。** 屏幕边缘、快速转相机、近云视差是必然失败区。讲座的回退是低分缓冲，不是把历史像素拉变形。
- **云没有不透明 G-buffer 深度。** 用体积命中距离或累积中心深度做 reprojection，并用邻域 clamp 压鬼影。
- **先半分辨率再上采样。** 讲座明确 half-res + filter upsample。双边 / 深度感知上采样优于裸 bilinear，否则远山轮廓会被云糊进几何。
- **完整采样的指令数是剩余成本。** 噪声纹理已经很小，瓶颈在分支与算术。保持 cheap 路径短，比把 128³ 改成 64³ 更有效。
- **唯一显存应来自噪声纹理。** 若为每个时相烤 skydome，就已经回到他们放弃的方案。

### 5.6 不要从后续工作倒灌

2015 系统没有这些东西，实现「这篇」时不要一上来就加：

- 双瓣 HG、Frostbite 式多倍散射 octave（Hillaire 2016）
- Nubis Evolved 的 envelope / dimensional profile（Schneider 2022）
- 解析天空–云耦合的多次散射 LUT

先把 Perlin-Worley、三预设高度、Beer–HG–Powder、cone 6 样本、cheap/full 切换、1/16 复用做稳，再考虑后续论文。

## 6. 总结结论

这篇课程讲的不是「如何更物理地解云的辐射传输」，而是 **如何用极少的独特纹理和一次可中断的 ray march，在主机帧预算里画出可导向、可演化、多种云型并存的体积天空**。

结论可以收成五条：

1. **云是规则，不是资产。** 形状来自 Perlin-Worley 骨架 + Worley 侵蚀 + 高度预设；分布来自天气场的 coverage / type / precipitation。演化是风与天气模拟的副产品，不必播放体积动画。
2. **外观由三个近似锁定，而不是提高采样密度。** Beer 管厚度，HG 管银边，Powder 管背光暗边；降水只加吸收。这三项对上了，64 次视线 + 6 次 cone 就够用；对不上，加采样也只是更贵的棉花。
3. **性能来自「空处不做工」。** 高频细节在建模上就是边缘侵蚀，所以空区只读低频。同一事实支撑 cheap/full 切换、光照在 alpha>0.3 降级、高层云改 2D。优化和造型是同一件事的两面。
4. **球壳大气是正确性，不只是美化。** 云沿地平线下沉、远景尺度、与山脉的遮挡关系，都依赖射线–球交而不是相机上方的盒子。
5. **时间复用是产品化的分界线。** 完整算法约 20 ms；1/16 更新 + 重投影 + 半分辨率大约 2 ms、约 20 MB。没有这项，前面所有工作停在技术演示。

对工程上的直接含义：先实现「采样器 + 球壳 march + Beer–HG–Powder」，用全分辨率、每像素每帧验证造型和光照；确认银边、暗边、云底丝状、天气图驱动都对了，再接入 cheap/full 与时间复用。次序反了，优化伪影会和造型错误缠在一起，很难拆。
